# Документация Planny

Planny — закрытый планировщик для одной семьи: личные календари, совместные события, задачи и общие доски со списком, Kanban и календарём. Он работает на домашнем сервере. Основной клиент — адаптивный сайт, локальные сервисы подключаются к тому же API по ключу.

| Документ | Что внутри |
|---|---|
| [features.md](features.md) | Что умеет продукт: роли, права, правила календаря, задач, ассистента и уведомлений, ключевые сценарии |
| [architecture.md](architecture.md) | Компоненты, сеть, авторизация, время, серии, напоминания, синхронизация, стек, структура репозитория, тесты, ключевые решения |
| [data-model.md](data-model.md) | Схема PostgreSQL |
| [api.md](api.md) | Правила API v1, поведение маршрутов, маршруты BFF, команды CLI |
| [frontend.md](frontend.md) | Устройство SPA, экраны, состояния, подписи |
| [deploy.md](deploy.md) | Установка на сервер, обновление, откат, проверки, место на диске |
| [../deploy/backup/README.md](../deploy/backup/README.md) | Резервные копии и восстановление |

## Где источник правды

- **Контракт API** — сгенерированный `backend/openapi.json` и клиент `web/src/api/schema.d.ts` (`make openapi`). [api.md](api.md) описывает правила и поведение, которых в схеме не видно.
- **Схема БД** — модели SQLAlchemy и миграции Alembic в `backend/migrations`. [data-model.md](data-model.md) объясняет смысл таблиц и ограничений.
- **Всё остальное** — документы этой папки. Если документ расходится с кодом, верен код, а документ нужно поправить.
