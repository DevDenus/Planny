# Документация Planny

Planny — закрытый планировщик для одной семьи: личные календари, совместные события, задачи и общие доски со списком и Kanban. Он работает на домашнем сервере. Основной клиент — адаптивный сайт, а локальные сервисы подключаются к тому же API по ключу.

**Статус:** проектирование завершено, кода ещё нет. Следующий шаг — этап 1 из [roadmap.md](roadmap.md).
