# Документация Planny

Planny — закрытый планировщик для одной семьи: личные календари, совместные события, задачи и общие доски со списком и Kanban. Он работает на домашнем сервере. Основной клиент — адаптивный сайт, а локальные сервисы подключаются к тому же API по ключу.

**Статус:** этапы 1–7 завершены: вход, сессии, CLI, резервные копии, каркас SPA, доски, задачи, Kanban, календарь, серии, напоминания и ключи интеграций работают в локальном Compose и проверены сквозными сценариями. Следующий шаг — этап 8 из [roadmap.md](roadmap.md).
