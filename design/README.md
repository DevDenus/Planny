# Дизайн Planny

Стиль приложения задают [референсы](references/). Он общий для всех экранов: экран без своего референса строится в том же стиле из тех же компонентов, поэтому отдельные макеты всех экранов не нужны.

Референсы сгенерированы нейросетью. Это ориентир по визуалу, а не спецификация, поэтому дословно повторять их не нужно. При расхождении верен `docs/frontend.md`.

Там же описано, [где референсы расходятся с документом](../docs/frontend.md#референсы) и [на что опирается каждый экран](../docs/frontend.md#5-карта-экранов).

Токены стиля и компоненты живут в коде, в `web/`. Если для сложного экрана всё же понадобится отдельный макет, он кладётся в `design/screens/` с именем `<экран>-<desktop|mobile>[-<состояние>]`, например `event-form-mobile-conflict.png`.
