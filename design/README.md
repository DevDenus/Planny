# Макеты Planny

Сюда кладём результаты дизайна по [docs/frontend.md](../docs/frontend.md).

```
design/
  references/   визуальные референсы
  tokens/       цвета, типографика, отступы
  components/   общие компоненты
  screens/      экраны
```

Имена файлов экранов: `<экран>-<desktop|mobile>[-<состояние>]`, например `calendar-month-desktop.png` или `event-form-mobile-conflict.png`.

Если макеты сделаны в виде кода, кладём их в те же папки. В `web/` они попадают только через обычную разработку.

## Референсы

[references/](references/) содержит изображения экранов, сгенерированные нейросетью. Это ориентир по визуалу, а не спецификация, поэтому дословно повторять их не нужно. При расхождении верен `docs/frontend.md`.

Там же описано, [где референсы расходятся с документом](../docs/frontend.md#референсы) и [какому экрану соответствует какой файл](../docs/frontend.md#5-карта-экранов).
